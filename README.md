A Colab notebook that detects and corrects LLM hallucinations by checking each generated sentence against Wikipedia. It scores risk with FAISS retrieval, NLI, atomic-fact checks, model consensus and an error taxonomy, then replaces high-risk sentences with retrieved facts. It is tested on real generations and on a benchmark with injected errors (wrong year, number or entity), comparing a retrieval-only baseline with the full ensemble. Outputs include plots, JSON/CSV exports and an optional Streamlit dashboard.
